# Форматы

Оверлею нужны два JSON. Первый меняется с каждым забегом и приходит как есть
из дневника, второй собирается под картинку.

## Трек с координатами

Тот же массив точек, что отдаёт дневник платформы. Модуль берёт из каждой
точки только координату, остальные поля не трогает:

```json
[
  { "index": 0, "distance": 0, "coordinate": [-9.398806, 38.872565, 152.2], "hr": 90 },
  { "index": 1, "distance": 3.1,  "coordinate": [-9.398818, 38.872591, 152.2], "hr": 90 }
]
```

Порядок в `coordinate` — `[долгота, широта, высота]`. Высота не обязательна.

Понимаются и более простые записи: `[[lon, lat], …]`, `{ "lon": …, "lat": … }`,
`{ "coordinates": [...] }`. Точка, у которой координаты нет или она `null`,
пропускается молча — у хвостовых точек дневника часть полей пустая, и это
нормально.

Трек можно не передавать вовсе: тогда рисуется один столбик цифр.

## Цифры забега

```json
{
  "rows": [
    { "icon": "run",       "value": "21.29", "unit": "km" },
    { "icon": "stopwatch", "value": "5:07",  "unit": "min/km" },
    { "icon": "mountain",  "value": "304",   "unit": "m" },
    { "icon": "heart",     "value": "144",   "unit": "bpm" },
    { "icon": "metronome", "value": "168",   "unit": "step/min", "accent": true }
  ],
  "track": { "show": true, "accent": true }
}
```

| поле | что делает |
|---|---|
| `icon` | значок слева: `run`, `stopwatch`, `mountain`, `heart`, `metronome`. Незнакомое имя — не ошибка, строка просто рисуется без значка |
| `value` | само число, строкой. Пишется как есть: `21.29`, `5:07`, `1:49:18` |
| `unit` | подпись мелким после числа. Можно опустить |
| `accent` | красный вместо синего |
| `show` | `false` — строку не рисовать. По умолчанию рисуются все |
| `track` | показывать ли маршрут и каким цветом. Необязательный блок |

Строки берутся по порядку, сколько дадите — столько и нарисуется.

Убрать метрику с картинки можно двумя способами, и оба рабочие:

```json
{ "icon": "heart", "value": "144", "unit": "bpm", "show": false }
{ "icon": "heart", "value": "", "unit": "bpm" }
```

`show: false` — когда состав строк выбирает человек и выбор надо сохранить.
Пустое `value` — когда JSON собирается шаблоном и вырезать поле неоткуда.
Скрытая строка не оставляет после себя пустого места: следующая поднимается
на её место.

Вместо объекта можно передать сразу массив строк — `rows` тогда не нужен.

## Параметры интервалов — третий файл

У интервальной тренировки бывает третий JSON: разбор по быстрым и медленным
отрезкам. Если он передан, по умолчанию рисуется он, а не общие цифры.

```json
{
  "columns": [
    { "title": "Быстро", "rows": [
      { "icon": "stopwatch",   "label": "среднее время",      "value": "00:38" },
      { "icon": "speed",       "label": "средний темп",       "value": "03:10" },
      { "icon": "delta",       "label": "разброс времени",    "value": "00:01" },
      { "icon": "heart-solid", "label": "средний пульс",      "value": "153" },
      { "icon": "distance",    "label": "средняя дистанция",  "value": "0.2", "unit": "км" },
      { "icon": "metronome",   "label": "каденс",             "value": "172" },
      { "icon": "repeat",      "label": "количество интервалов", "value": "15" }
    ]},
    { "title": "Медленно", "accent": true, "rows": [
      { "icon": "stopwatch",   "label": "среднее время",      "value": "00:46" },
      { "icon": "speed",       "label": "средний темп",       "value": "03:50" },
      { "icon": "delta",       "label": "разброс времени",    "value": "00:01" },
      { "icon": "heart-solid", "label": "средний пульс",      "value": "130" },
      { "icon": "distance",    "label": "средняя дистанция",  "value": "0.2", "unit": "км" },
      null,
      { "icon": "repeat",      "label": "количество интервалов", "value": "14" }
    ]}
  ]
}
```

Строки колонок **выровнены по номеру**: пятая строка слева и пятая справа
встают на одну линию, чтобы их можно было сравнить взглядом. Отсюда `null`
в примере: каденс есть только у быстрых отрезков, и без пустого места
«количество интервалов» в правой колонке уехало бы на строку выше.

| поле | что делает |
|---|---|
| `title` | заголовок колонки, им же задаётся цвет значков |
| `accent` | вся колонка красная вместо синей |
| `label` | подпись мелким над числом; длинная переносится сама |
| `value`, `unit`, `icon`, `show` | как в обычных цифрах |

Значки для интервалов: `stopwatch`, `speed`, `delta`, `heart-solid`,
`distance`, `metronome`, `repeat`.

Колонок может быть и больше двух — раскладка считается по содержимому.

## Числа приходят готовыми

Оверлей ничего не считает по треку, кроме самой линии. Это не упрощение,
а осознанный выбор: на том же забеге на 21.29 км сырая сумма подъёмов по
точкам даёт **344 м**, а платформа показывает **304 м** — она сглаживает
шум высотомера. Каденс в треке лежит на одну ногу (в среднем 81), а человек
привык видеть **168**. Считай оверлей сам — цифры на картинке разошлись бы
с цифрами в дневнике, и объяснить это было бы нечем.

Пульс, для сравнения, сходится: среднее по точкам 143.4 → 144.
