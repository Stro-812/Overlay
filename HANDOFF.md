# Оверлей забега — вводная для продолжения

Это брифинг для нового разговора с Claude. Открыть папку, дать эту страницу
целиком — и можно работать дальше без расспросов.

---

## 1. Что это

Инструмент делает картинку для соцсетей из двух JSON: координаты трека и
цифры забега. На выходе — фотография с уже наложенным оверлеем (слева
столбик метрик со значками, рядом контур маршрута, в углу знак S10) либо,
отдельной кнопкой, прозрачный PNG для тех, кто накладывает сам в редакторе.

Весь рендер идёт в браузере: ни сервера, ни ключей, ни сборки. Зависимостей
ноль, Playwright в `devDependencies` нужен только прогонам. Конечная точка
назначения — **кнопка на сайте stro.run**, поэтому библиотека сделана как
три ES-модуля и одна функция, а не как приложение.

- Репозиторий: <https://github.com/Stro-812/Overlay> (ветка `main`)
- Страница подбора: <https://claude.ai/artifact/6yUDmWcVjYrkBddhUE9cFR> (версия 15)
- Автор задачи и владелец обоих адресов: mail@stro.run

## 2. Запуск

```bash
npm install      # ставит только Playwright
npm test         # рендер в Chromium + прогон демо-страницы; должно быть «проверки прошли»
npm run demo     # http://127.0.0.1:4173 — подобрать раскладку под свой забег
npm run page     # собрать страницу подбора в page/out/overlay-demo.html
npm run icons    # лист иконок крупно, в test/out/icons.png
```

Нужен Node 20+ (используются `import.meta.dirname` и `structuredClone`) и
Python 3 — только для `npm run page`.

Если Playwright не скачал Chromium: `npx playwright install chromium`.

## 3. Карта кода

```
src/
  overlay.js   раскладка, выбор режима, публичные функции, DEFAULTS
  track.js     проекция координат, поворот, упрощение линии
  icons.js     контуры значков на сетке 32×32
  intervals.js две колонки разбора интервалов
  logo.js      знак S10 в кривых, безопасная зона, замер яркости подложки
demo/index.html   локальная страница подбора (по http, модулями)
page/             исходники опубликованной страницы — всё вшито в один файл
test/             прогоны в Chromium
docs/FORMATS.md   оба JSON, поле за полем
docs/EMBED.md     как повесить на кнопку сайта, замеры производительности
```

Публичные функции `src/overlay.js`:

| функция | что делает |
|---|---|
| `renderComposite(data, options)` | фотография с наложенным оверлеем → `Blob`. **Основной путь.** |
| `renderOverlay(data, options)` | прозрачный PNG → `Blob` |
| `composeToCanvas(data, options, canvas)` | то же, но в готовую канву — этим живёт предпросмотр |
| `renderToCanvas(data, options, canvas, {keep})` | только оверлей в канву |
| `downloadComposite` / `downloadOverlay` | обёртки, сохраняющие файл |

`data` — это `{ track, stats, intervals, photo }`, `options` — раскладка
(`DEFAULTS` в `src/overlay.js:26`). **Разделение обязательно**: в первой
версии всё лежало в одном объекте, и точки трека затирали настройки трека.

Раскладка задана в долях ширины, поэтому одни и те же числа одинаково
ложатся на квадрат для ленты и на вертикаль для сторис.

## 4. Два JSON и переключатель

Полное описание — `docs/FORMATS.md`, образцы — `test/fixtures/`.

- `stats.json` — строки со значком, числом и единицами; `show: false` убирает
  строку, остальные сдвигаются.
- `intervals.json` — разбор интервальной тренировки, колонки «Быстро» и
  «Медленно», строки выровнены по индексу для сравнения; `null` держит
  пустое место в колонке.
- **Если пришли оба, по умолчанию показываются интервалы** (`opts.mode`
  перебивает это вручную). Из колонок по умолчанию рисуется одна, «Быстро» —
  так просил владелец; `intervals.columns = 0` вернёт все.

Цифры **никогда не считаются из трека**. Это решение, а не недоделка: у
платформы набор высоты 344 м против 304 м посчитанных по точкам, каденс 81
против 168 (шаги одной ноги против обеих). Числа приходят готовыми из
дневника — так на картинке ровно то, что человек видит в своём профиле.

## 5. Знак S10

Знак **обязателен** и пользователю не отключается. Он в кривых
(`LOGO_SVG` в `src/logo.js`), обведён потрейсом из присланного PNG.

- Двигается только внутри безопасной зоны соцсетей:
  `SAFE = { top: 0.14, right: 0.06, bottom: 0.19, left: 0.06 }` — под
  интерфейс сторис не уедет.
- Вариантов два: цветной и белый. Выбор **не отдан пользователю**: яркость
  меряется по площадке под самим знаком (относительная светимость
  `0.2126R + 0.7152G + 0.0722B`), светлая подложка → цветной, тёмная → белый.
- Замер берётся **до** отрисовки знака — иначе знак померил бы сам себя.

## 6. Страница подбора: сборка и публикация

`page/build.py` склеивает `src/*.js` + `page/controller.js` в один
`<script type="module">` внутри `page/shell.html`, подставляя образцы трека,
цифр и интервалов прямо в код.

Почему не просто модули: артефакт — это одна страница без сети, импортов
между файлами там нет. Отсюда две проверки, которые роняют сборку:

1. **Совпадение имён верхнего уровня.** В модулях два `metrics` в разных
   файлах — норма, в общей области видимости — SyntaxError на весь скрипт, и
   страница не заводится вовсе. Это уже случалось; теперь ловится сборкой.
2. **Закрывающий тег внутри строки** — оборвал бы скрипт посреди кода.

Публикация (та же учётная запись, инструмент `Artifact`):

```
Artifact  action: "read",    url: "https://claude.ai/artifact/6yUDmWcVjYrkBddhUE9cFR"
Artifact  file_path: "page/out/overlay-demo.html",
          url: "https://claude.ai/artifact/6yUDmWcVjYrkBddhUE9cFR",
          capabilities: { downloads: {} }
```

Сначала `read`, потом публикация с тем же `url` — иначе адрес будет новый, и
ссылка, которая уже у человека в закладках, останется на старой версии.

**Важно про учётную запись.** Артефакт принадлежит mail@stro.run. Claude в
другой учётной записи обновить его по этому адресу не сможет — опубликуется
отдельная страница со своим адресом. Если тюнинг ведётся из другого аккаунта,
это нормальный рабочий режим: правьте `page/`, публикуйте свой адрес, а
владелец в конце выкатит собранный файл поверх боевого адреса.

Скачивание на странице идёт через `claude.use('downloads')`: в песочнице
артефакта страница не может отдать файл сама. В `demo/index.html` и на сайте
работает обычный `<a download>` — поэтому `page/controller.js` проверяет
наличие `window.claude` и не падает без него.

## 7. Правила, которые дорого дались

Это не стиль, а следы конкретных поломок. Каждое стоило отдельного разбора.

**Предпросмотр обязан идти тем же кодом, что и файл.** Три раза подряд
причиной жалобы было одно: файл выходил правильным, а врал предпросмотр.
Если правите вывод — правьте общий путь (`composeToCanvas`), а не рисование
на странице отдельно.

**Прозрачный PNG на телефон не отдавать.** Мессенджеры пережимают PNG в
JPEG, а у JPEG альфы нет; просмотрщики рисуют прозрачность шахматкой, и если
человек снял экран, шахматка запекается в картинку. Поэтому основная кнопка
отдаёт готовую картинку. Кнопка с прозрачным PNG осталась, но названа так,
чтобы нельзя было перепутать.

**Размер предпросмотра ограничен 1400 точками** по длинной стороне. Телефонный
снимок — восемнадцать миллионов точек, перерисовывать их на каждое движение
ползунка незачем: раскладка задана в долях и от разрешения не зависит. В файл
уходит полный размер. Замеры в `docs/EMBED.md`: 33.9 мс → 10.9 мс.

**Снимок разбирается один раз.** В `src/overlay.js` есть кэш на один слот
(`lastPhoto`) и проверка `if (canvas.width !== width)` — присваивание
`canvas.width` перевыделяет канву, даже если размер тот же. Прогон следит,
что на пять кадров приходится один разбор. Это была настоящая просадка
производительности, а не ощущение.

**Поворот трека применяется до вписывания в рамку** (`trackPath(track, box,
{rotate})`), иначе повёрнутый маршрут перестаёт заполнять место.

**Цвет доходит до цифр, а не только до значков.** В интервалах текст рисуется
`L.ink ?? colour` — раньше там был прибитый `#111111`.

**Ширину строки канва меряет тем шрифтом, который загружен в эту секунду.**
Поэтому модуль ждёт `document.fonts.load` до первого измерения.

**Вёрстка.** `position: sticky` держится за область грида — внутри ячейки,
высота которой задана содержимым, он не работает; колонки объявлены
`minmax(0, 1fr)`, иначе дорожка `auto` меряется по самому длинному имени
файла и колонки наезжают друг на друга; у кадра предпросмотра точная
`aspect-ratio: W / H` и никакого `object-fit: contain` — он давал полосу
прозрачных пикселей над фотографией.

## 8. Данные и приватность

**Настоящий трек в гит не кладётся.** Это GPS живого человека, вплоть до
точки старта у дома. `test/fixtures/track.json` в `.gitignore`, прогоны
работают на `track.sample.json` — это синтетика, не обрезанный настоящий
трек. В архиве настоящего трека тоже нет; если для проверки нужен реальный
маршрут, попросите его у владельца напрямую.

Репозиторий `Stro-812/Overlay` сейчас **публичный** — владелец об этом знает
и решения пока не менял. Стоит помнить, если соберётесь класть туда что-то
внутреннее.

## 9. Как проверять

В этом проекте заведено проверять измерением, а не глазами, и это себя
окупило: «ползунок виден» однажды прошло геометрической проверкой, пока
ползунок был накрыт липким блоком. С тех пор попадание проверяется
`document.elementFromPoint`, прозрачность — чтением альфы у пикселей,
производительность — счётчиком разборов снимка и таймером.

`npm test` уже содержит: пустую альфу у PNG, отсутствие просвечивающих
пикселей у готовой картинки, смену сторон рамки при повороте на 90°,
`show: false` наравне с пустым значением, интервалы по умолчанию, знак внутри
безопасной зоны во всех четырёх углах, белый на тёмном и цветной на светлом,
кадр «тёмный верх — светлый низ», одну колонку против всех, один разбор
снимка на пять кадров.

Новую заметную правку хорошо бы дополнить таким же прогоном — они дешёвые и
ловят ровно то, что здесь уже ломалось.

## 10. Что можно крутить дальше

Ничего из этого не начато; порядок — по убыванию пользы, как её видно
отсюда.

- **Пресеты раскладки** под ленту (1:1), сторис (9:16) и обложку. Сейчас всё
  подбирается ползунками и переносится в код руками.
- **Перетаскивание оверлея** мышью и пальцем. Разбирали, не делали: ползунки
  дают точность и повторяемость, перетаскивание — скорость; ограничения —
  палец закрывает то, что двигает, и нужна отдельная привязка к безопасной
  зоне.
- **Вторая раскладка**: сейчас она одна — столбик слева, маршрут справа.
- **Выбор значка для строки** — пока значок жёстко привязан к имени метрики.
- **Готовая картинка только из одной фотографии**: ни рамок, ни коллажей, ни
  обрезки под формат сторис.
- **Номер версии на странице подбора** — просили, руки не дошли; сейчас
  версию видно только в истории артефакта.
