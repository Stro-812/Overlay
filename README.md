# Оверлей забега

Два JSON — на выходе прозрачный PNG, который кладётся поверх фотографии с
забега и уходит в соцсети.

Слева столбик метрик со значками, рядом контур маршрута. Фон прозрачный:
рисуются только цифры и линии.

## Что внутри

- **Рендер в браузере.** Ни сервера, ни ключей, ни сборки: три ES-модуля и
  одна функция. Вешается на кнопку сайта.
- **Ноль зависимостей.** Canvas 2D и `Path2D` — всё. Playwright в
  `devDependencies` нужен только прогонам.
- **Раскладка в долях ширины.** Одни и те же настройки одинаково ложатся на
  квадрат для ленты и на вертикаль для сторис.
- **Свои иконки.** Бегун, секундомер, горы, сердце и метроном нарисованы
  контурами на сетке 32×32 и правятся прямо в коде.
- **Цифры не пересчитываются.** Приходят готовыми вторым JSON — почему
  именно так, написано в [docs/FORMATS.md](docs/FORMATS.md).

## Команды

```bash
npm install
npm run demo     # http://127.0.0.1:4173 — подобрать раскладку под свой забег
npm test         # прогон рендера и демо-страницы в Chromium
npm run icons    # лист иконок крупно, в test/out/icons.png
```

`npm run demo` — страница, куда кидают трек, цифры и фотографию: ползунки
двигают раскладку, а готовый объект настроек копируется в код кнопки.

## Как встроить

```js
import { downloadOverlay } from '/js/overlay/overlay.js';

button.addEventListener('click', async () => {
  await downloadOverlay({ track, stats }, { width: 1080, height: 1080 });
});
```

Подробно — [docs/EMBED.md](docs/EMBED.md).

## Как устроен код

```
src/
  overlay.js   раскладка и рисование, публичные функции
  track.js     проекция координат и упрощение линии
  icons.js     контуры значков
demo/
  index.html   страница для подбора раскладки
scripts/
  serve.mjs    сервер демо-страницы
test/
  browser.mjs  общая обвязка: браузер, которому файлы отдаются по http
  render.mjs   рендер в Chromium и проверки прозрачности
  icons.mjs    лист иконок крупно — чтобы править контуры глазами
  demo.mjs     прогон демо-страницы с настоящими файлами
docs/
  FORMATS.md   оба JSON
  EMBED.md     как повесить на кнопку сайта
```

Трек проецируется равнопромежуточно с поправкой на косинус широты: на
дистанциях до сотни километров расхождение с меркаторовской проекцией
меньше толщины линии. Точки, не меняющие форму, выбрасываются алгоритмом
Рамера — Дугласа — Пекера с допуском в полпикселя — иначе стотысячеточечный
трек заметно тормозит на телефоне.

## Чего пока нет

- Логотип и подписи организатора в оверлей не попадают — их кладут в
  редакторе поверх.
- Иконка одна на метрику; выбрать другой значок для той же строки нельзя,
  кроме как дописав контур в `src/icons.js`.
- Раскладка одна: столбик слева, маршрут справа. Пресетов под сторис и
  ленту пока не заведено, подбирается ползунками.
